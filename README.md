# Disease Screening Data Analysis in R

An R coursework project analyzing daily disease-screening records from two fictional countries. The project combines files into a single dataset, identifies positive screens, summarizes patient characteristics, and visualizes screening patterns over time.

This repository is part of my data analysis portfolio. It demonstrates my experience with base R, custom functions, data manipulation, exploratory analysis, and visualization with `ggplot2`.

## Project background

The Introduction to Biocomputing assignment presents a hypothetical disease outbreak in Countries X and Y. Each screening record contains gender, age, and the presence or absence of ten molecular markers. Under the assignment's definition, a record is classified as positive when at least one marker is present.

The analysis explores two questions:

1. Which country shows earlier evidence of positive screens?
2. How do marker patterns differ between the countries, and what questions might those differences raise about a shared vaccine response?

This is an educational exercise, not a CDC engagement or a clinical study. The assignment instructions and supplied datasets are included in the repository.

## R skills demonstrated

- **Custom functions:** Separate supporting functions from the main analysis script and load them using `source()`.
- **Batch file processing:** Use `list.files()`, loops, and `read.csv()` to import daily screening files.
- **Metadata extraction:** Use `gsub()` to extract country identifiers and screening days from folder and file names.
- **Data manipulation:** Combine datasets with `rbind()` and `cbind()`, subset records by country and day, and identify positive screens using marker totals.
- **Missing-value handling:** Implement options to remove missing records or retain them with or without a warning.
- **Descriptive summaries:** Calculate screening counts, positive-screen proportions, gender ratios, and age summaries.
- **Time-series summaries:** Calculate daily positive-screen counts and cumulative totals using `cumsum()`.
- **Visualization:** Create line plots and stacked bar charts with `ggplot2` and export figures with `ggsave()`.
- **Data quality review:** Identify implausible ages, including a maximum recorded age of 423 years.

## Analysis workflow

1. Read daily screening CSV files from `countryX/` and `countryY/`.
2. Add country and day-of-year columns to each file.
3. Combine records and export `compiled_sharma_version.csv`.
4. Identify positive-screen records and export `subPatient.csv`.
5. Summarize daily positive screens and cumulative counts for each country.
6. Compare the frequency of individual markers between countries.
7. Export three figures as PDF files.

The supporting script also contains an attempted text-to-CSV conversion function; its current implementation is incomplete (see limitations below).

Positive screens account for approximately **56.6%** of all records. These are screening-record counts; the files do not provide a unique patient identifier for determining whether an individual was screened more than once.

## Findings

- **Earlier detected positives in Country X:** The stored data contain positive screens beginning on day 120 in Country X and day 139 in Country Y. This supports earlier detection in Country X, but screening records alone cannot establish where the outbreak originated.
- **Different marker patterns:** Markers 1–5 are much more frequent in Country X, while markers 6–10 are more frequent in Country Y. These differences motivate further investigation of strain variation; marker counts alone do not establish vaccine effectiveness.
- **Data quality concerns:** Implausible ages should be investigated before demographic interpretation. The original analysis flags this issue but does not correct the records.

## Reviewing and running the project

Open `Rproject.Rproj` in RStudio to review the scripts, datasets, and saved outputs. The plotting dependency is `ggplot2`:

```r
install.packages("ggplot2")
```

The repository preserves the original coursework scripts. **They require adjustments before the complete analysis can run on another computer:**

1. Remove the personal `setwd()` calls in both scripts and run from the repository root.
2. Change the source call in `analysis.R` to match the exact filename: `source("SupportingFunction.R")`.
3. Change `compile_csv(..., "Warn")` to `compile_csv(..., "Warning")` to use the implemented warning option.
4. Complete `txtTOcsv()` by writing each imported table to `csvOutput`, or skip conversion when using the CSV files already provided.

After these adjustments, run `analysis.R` from the repository root. The script writes CSV summaries and PDF figures into that folder.

## Limitations and opportunities for improvement

- Daily and cumulative summaries use fixed indices based on 56 days per country; these should be replaced with grouped calculations before adding new dates or countries.
- `sumdata()` returns an infected proportion, despite labeling it as a percentage; multiply by 100 to report a percentage. Its male-to-female statistic is a ratio, not a percentage.
- Positive-screen calculations need explicit handling of missing marker values when retaining incomplete records.
- The saved dataset shows Country X positives on day 120; the original script's approximate day-122 interpretation should be updated.
- The full R workflow has not been rerun as part of preparing this README. The numerical summary above was independently checked from the stored CSV files.
